## Config env
1. create new conda env  
    ```bash
    conda create -n unimatch
    conda activate unimatch
    ```
2. some packages
   ```bash
   pip install torch==2.4.0 torchvision==0.19.0 --index-url https://download.pytorch.org/whl/cu124
   pip install tensorboard==2.9.1 einops opencv-python>=4.8.1.78 matplotlib
    ```
    会出现一些报错，一些依赖包未安装
    ```bash
    pip install pyserial click
    ```
    然后检查是否还缺少其他的包
    ```bash
    pip check
    ```
    再安装
    ```bash
    pip install pyyaml decorator
    ```
    再检查是否还缺少其他的包
    ```bash
    pip check
    ```
3. some error  
    numpy要降级到1.24.3
    ```bash
    pip install numpy==1.24.3
    ```
    运行脚本发现要安装skimage
    ```bash
    pip install scikit-image
    ```
4. install successfully  
    ```bash
    scripts/gmstereo_demo.sh
    ```
    运行成功，说明环境配置成功。
